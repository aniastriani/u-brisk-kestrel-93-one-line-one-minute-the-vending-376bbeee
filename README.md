An entry for the [make.fun bounty "One Line, One Minute: The Vending Machine Pickup Line Contest"](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

## What it does

`main.py` (pure Python standard library, no dependencies) writes a single
pickup line — spoken by a vending machine to a passing human — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is 140 characters, inside the
1–200 character gate: the machine hums, its coils spin, button B7 is
pressed, the exact change stays with the human, and the punch lands on
the last Snickers… and the machine's heart.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/output python3 main.py
cat /tmp/output/entry.txt
```
